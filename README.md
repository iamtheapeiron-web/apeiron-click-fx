# APEIRON Click FX

**Make viewer clicks part of your Twitch stream.**

APEIRON Click FX is an interactive Twitch extension that turns viewer clicks into visual effects. Built for streamers who want a lightweight way to make their stream more interactive.

## Effects

- CRT Magnet (hold interaction)
- Static Burst
- Analog Glitch
- RGB Split
- Signal Loss

The extension includes configurable effect selection and intensity options. Available behavior depends on the streamer's configuration.

## How to find it

Open the Extensions section of your [Twitch Creator Dashboard](https://dashboard.twitch.tv/) and search for **APEIRON Click FX**. Configure and activate the extension following Twitch's instructions.
